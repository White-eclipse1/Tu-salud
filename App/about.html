Acerca de
Tu Salud

Un sistema de análisis predictivo de riesgos médicos construido con machine learning y datasets clínicos reales.

¿Qué es Tu Salud?

Tu Salud es un proyecto académico de análisis predictivo de riesgos médicos desarrollado como parte de un ejercicio de ciencia de datos e ingeniería de software. Su objetivo es construir un sistema completo que, a partir de datos clínicos de un paciente, sea capaz de estimar el riesgo de padecer tres condiciones crónicas de alta prevalencia: diabetes, hipertensión arterial y paro cardíaco, además de una evaluación de riesgo general de salud.

El proyecto integra técnicas de aprendizaje automático supervisado y no supervisado, procesamiento de datos médicos reales y una interfaz web para presentar los resultados de forma accesible y clara.

🔬

Esta versión del frontend es una simulación visual demostrativa. Los cálculos de riesgo mostrados son ilustrativos y están basados en heurísticas clínicas simplificadas. En la versión final, el frontend se conectará con los modelos predictivos de Python entrenados con los datasets reales del proyecto.

Riesgos analizados

Condiciones médicas objetivo

El sistema predice la probabilidad de riesgo individual para cuatro evaluaciones:

⚠️ Riesgo general de salud 🩸 Diabetes mellitus ❤️ Hipertensión arterial ⚡ Paro cardíaco
Variables clínicas

¿Qué datos se ingresan?

El modelo utiliza las siguientes variables como entrada:

  • Edad y sexo biológico
  • Glucosa en sangre (mg/dL)
  • Presión arterial sistólica (mmHg)
  • Índice de Masa Corporal (IMC)
  • Frecuencia cardíaca (bpm)
  • Colesterol total (mg/dL)
  • Tabaquismo y actividad física
  • Antecedentes familiares
Machine Learning

Tipos de modelos utilizados

El proyecto emplea dos enfoques complementarios de aprendizaje automático:

  • No supervisado: Clustering para identificar perfiles de riesgo general sin etiquetas previas.
  • Supervisado: Clasificadores entrenados para predecir diabetes, hipertensión y paro cardíaco.
Python scikit-learn pandas Jupyter DVC
Datos reales

Datasets médicos utilizados

El proyecto usa tres datasets clínicos reales gestionados con DVC:

  • diabetes.csv — Datos de pacientes con indicadores de diabetes.
  • Hipertension_Arterial_Mexico.csv — Registros de presión arterial en México.
  • Medicaldataset.csv — Dataset médico general para riesgo cardíaco.

Aprendizaje No Supervisado

Identificación de perfiles de riesgo

Se utiliza un modelo de clustering (como K-Means o DBSCAN) para agrupar pacientes con características similares sin necesidad de etiquetas previas. Esto permite identificar automáticamente perfiles de riesgo general y descubrir patrones ocultos en los datos clínicos.

  • Segmentación automática de pacientes
  • Detección de anomalías clínicas
  • Perfil de riesgo sin etiquetas
Aprendizaje Supervisado

Predicción de condiciones específicas

Se entrenan clasificadores binarios específicos para cada condición usando los datasets etiquetados. Los modelos aprenden a distinguir entre pacientes con y sin riesgo para cada enfermedad objetivo.

  • Predicción de diabetes
  • Predicción de hipertensión arterial
  • Predicción de paro cardíaco
  • Validación cruzada y métricas (AUC, F1)
